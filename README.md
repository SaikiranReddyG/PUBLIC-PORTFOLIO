# Saikiran Reddy Gangula — portfolio

Source of [saikiran-reddy-gangula.space](https://saikiran-reddy-gangula.space): research profile, publications and projects (IoT and network security).

Built with Vite, React, Tailwind CSS and i18next (English / French). Deployed on Vercel from `main`.

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build in dist/
```

Text lives in `src/locales/en.ts` and `src/locales/fr.ts`; pages are in `src/pages/`.
